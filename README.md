# zzzzz · AI 概念学习资料仓库

本仓库用于存放一套围绕 **AI / Agent 生态概念** 的生成式学习资料，以及驱动这些资料生成的 **concept-tutor（概念学习资料生成）技能**。仓库中的概念学习资料均以统一的五大模块结构产出（个人解释 / 核心机制 / 应用场景 / 边界辨析 / 来源链接），并要求**联网查证、逐条标注可复核来源**。

> ⚠️ 提示：本目录原为桌面临时文件夹 `zzzzz`（含空占位文件 `skll.txt`），被用作本仓库的根目录。如需纳入正式版本管理，建议重命名并建立 Git 仓库。

---

## 仓库用途

1. **沉淀可复用的概念学习技能**：`SKILL.md` 定义了一套"把任意陌生概念加工成结构化学习资料"的标准流程。
2. **存放按该技能产出的学习资料**：`skll/` 下是 HTML 格式的分主题学习资料，便于浏览器直接阅读与分享。
3. **沉淀概念间关系说明**：`concept-relationship.md` 用 Mermaid 流程图讲解 Agent / 上下文 / Skill 三者关系，作为三份资料的"串讲与索引"。

### SKILL.md 结构速览

- **YAML 元数据**：`name: concept-tutor`、`description`（触发说明）、`agent_created: true`。
- **正文**：适用场景 → 参数化输入（必填仅 concept）→ 概念归一化四步 → 7 步生成流程 → 固定五模块输出结构 → 资料来源要求 → A–E 自检清单。

## 调用方法

### 方式一：正式注册为用户级技能（推荐，支持自动触发）

1. 将技能目录放入用户级技能目录：
   `~/.workbuddy/skills/concept-tutor/`（内含 `SKILL.md`，可按需带 `assets/`、`references/`）。
2. 在 WorkBuddy 技能/能力管理界面确认该技能已**启用**（新放入的技能通常需要一次刷新/信任）。
3. 启用后两种触发方式：
   - **自动触发**：直接提一个概念学习需求，例如“帮我搞懂一下反脆弱”“解释什么是 B+ 树”，description 命中即自动加载执行。
   - **显式调用**：若技能支持命令调用，可使用斜杠命令（如 `/concept-tutor <概念名>`）。

### 方式二：作为流程文件手动遵循执行（无需注册）

1. 打开 `.zzzzz/SKILL.md`（或桌面已复制的一份）。
2. 将其流程交给支持"遵循文档指令"的 AI 执行，并给出要学习的**任意概念**作为输入。
3. 该 AI 将按 `SKILL.md` 的参数表取默认值、执行联网检索、产出五大模块资料。
   > 注：这是"按其规范执行"，不等同于平台级技能触发；正式工程化建议用方式一。

### 使用要求（技能自带）

- 所有事实性内容**必须联网查证**，禁止编造 URL / 数据 / 论文。
- 输出固定为**五大模块**，并附**来源链接表**与自检结果。
- 只给一个概念名即可开工，其余参数按默认值执行。
